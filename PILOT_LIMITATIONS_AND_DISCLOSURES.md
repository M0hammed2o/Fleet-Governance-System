# Pilot Limitations and Disclosures

- Tracker data remains synthetic or imported until an official provider connection is approved and implemented.
- Facial verification remains synthetic/provider-neutral until a real provider or local model is approved. Existing local engineering code is not production validation.
- Genbridge provides no stolen-vehicle recovery service.
- The application remains online-only; disconnected mutations are refused.
- Human UAT is separate from automated testing and is currently incomplete.
- No physical Android device has been verified in Phase 17A. The available Pixel 7 API 35 emulator remained offline; no emulator smoke result is claimed.
- iOS remains unverified.
- The internal pilot must not be used as a production safety, surveillance, criminal/fraud, employment, disciplinary, or automated adverse-decision system.
- Synthetic non-match or liveness outcomes are scenarios, not statements about a person. Provider unavailable is not failed identity.
- No external provider, production infrastructure, customer environment, remote backup, or production/staging activation exists.
