# Pilot External Auditor guide

## Role purpose and sign-in

Review only synthetic cases explicitly granted for a limited time. Sign in through the External Auditor portal with the dedicated case-scoped account; a normal tenant dashboard is not part of this role.

## Daily workflow and tasks

1. Confirm grant purpose, start/expiry and allowed download flags.
2. Open only listed case numbers; review permitted chronology, evidence and reports.
3. Download only when required and authorised; secure/delete the local copy under the UAT evidence rule.
4. Report questions through the named audit contact; request scope changes rather than manipulating URLs.

## Never do

Do not access unrelated cases, mutate any record, share/download beyond purpose, retain after expiry/revocation, seek restricted internal notes, or paste content into email/chat.

## Failure and escalation

Stop and report immediately if an unrelated case, restricted note, edit control, post-revocation access or customer information appears. Do not continue exploring a suspected access-control defect.

## Security, sign-out and quick reference

- [ ] Grant/case/purpose/expiry correct
- [ ] Only permitted evidence/report accessed
- [ ] No unrelated/restricted information visible
- [ ] Local evidence secured or deleted
- [ ] Sign out and confirm revocation when review ends
