# Genbridge Fleet Governance System — 15–20 minute demo script

Use only invented data. Keep a seeded synthetic tenant available in a second browser profile as a fallback.

1. **Boundary and registration (2 minutes).** Open `/register`. State that registration is development/approved-demo only and production fails closed. Create an invented company and first administrator; point out the terms and synthetic-data disclosure. Submit and show the automatic onboarding redirect.
2. **Company and fleet plan (2 minutes).** Save company contact/division fields. Declare eight vehicles and enter category counts that reconcile. Deliberately alter one count to show validation, then correct it. Explain loaded versus outstanding vehicles.
3. **Sites and gates (1 minute).** Add an invented site and gate. Explain that staff placement and gate operations remain tenant-scoped.
4. **Add a vehicle (2 minutes).** Add an 18-tonne truck and explain category-specific validation. Open its detail record, add service/expiry information, upload an abstract synthetic image and fabricated PDF, then view/replace/delete it through private signed access.
5. **Add a driver (2 minutes).** Add an invented driver with licence issue/expiry and permit status. Open driver details, add a non-person synthetic profile image and fabricated licence document. State that profile media never becomes biometric enrolment.
6. **Assign the driver (1 minute).** Open Assignments, choose driver/vehicle, enter the required reason and assign. Demonstrate that a conflict is refused unless explicit reassignment is selected, which ends the earlier row rather than overwriting history.
7. **Staff and guard approval (2 minutes).** Create a local Security Guard invitation with site/gate placement. Show that no email was sent and permission summaries are visible. Use a different authorised manager to approve with a mandatory reason; self-approval is refused. Explain that a pending guard cannot begin gate duty.
8. **Dashboard (2 minutes).** Show declared/loaded fleet, assigned/unassigned drivers, vehicle availability, expiry warnings, exceptions and gate activity. Use the responsive cards/table and open driver/vehicle links.
9. **Explain ratings (2 minutes).** In the fixed synthetic workspace show green, yellow and red examples. Open each factor/action list, calculation time and version. State explicitly that these are operational indicators, never allegations.
10. **Operational drill-down and limitations (2–3 minutes).** Open a driver and vehicle to show documents, assignment chronology, inspections, movements, open/resolved exceptions, investigations, audit chronology and tracker provenance. Point out the `DEMONSTRATION TRACKING — SYNTHETIC OR MANUALLY ENTERED; NOT A LIVE PROVIDER FEED` warning. If showing facial scenarios, read the exact label: **SYNTHETIC BIOMETRIC TEST — NOT REAL FACIAL VERIFICATION**. Explain that real provider integration, legal approval, hosted readiness and physical-device validation remain outside this phase.

Finish without deploying, publishing, connecting a provider, sending email or entering real information.
